# 🇩🇪 GermanQuest AI: A1-C2 Interactive German Learning Platform

An immersive, gamified web application designed to help learners master German from CEFR level A1 up to C2. Built with **React**, **Vite**, **Tailwind CSS**, and powered by **Google's Gemini AI**, this platform combines structured grammar notes with interactive practice modules.

---

## 🚀 Features

* **Complete A1–C2 Curriculum & Notes:** Elaborate grammar explanations, sentence structures, cases (Nominativ, Akkusativ, Dativ), verb conjugations, and prepositions with integrated bilingual English-German formatting.
* **Gamified Practice Arena:** 
  * **Flashcards:** Interactive vocabulary cards with hints and flip mechanics.
  * **Reading Comprehension:** Short AI-generated stories paired with quizzes and XP rewards.
  * **AI Writing Assistant:** Type German sentences and receive instant, constructive AI grading and correction from Gemini.
  * **Listening Practice:** Native audio pronunciation using browser Text-to-Speech integration.
  * **Speaking Practice:** Spoken German pronunciation assessment.
* **XP & Level Progression:** Earn experience points (XP) as you master topics and complete practice modules.
* **Bilingual UI:** Every term, title, and rule features German translations below the English text to organically build vocabulary.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Styling:** Tailwind CSS
* **AI Integration:** Google Gemini API (`gemini-1.5-flash`)
* **Deployment:** GitHub Pages (`gh-pages`)
